# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Use GitHub's private reporting instead:
**Security › Report a vulnerability** on this repository. You can expect an acknowledgement within a few days.

## Scope

Chat in Notch runs entirely on your Mac and does not talk to any server of its own. Reports that are in scope include:

- Conversations or attached images being written outside `~/Library/Application Support/ChatInNotch`.
- Anything that causes microphone audio or conversation text to leave the machine.
- Unsafe handling of attached files or pasted content.

Issues in Apple's frameworks or models should be reported to Apple.
